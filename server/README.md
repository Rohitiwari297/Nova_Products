# Nova Beauty – Backend

Nova Beauty is an on-demand home salon and beauty service platform that connects customers with professional beauticians, allowing users to discover beauty services and book appointments at their preferred date, time, and location.

The backend provides RESTful APIs to manage the platform's core operations, including user authentication, service management, appointment scheduling, beautician management, and administrative operations.

### Key Features

- **Authentication & Authorization:** Secure login, registration, JWT authentication, and role-based access control.
- **User Management:** Customer profile and account management.
- **Service Management:** Manage salon services, categories, pricing, and availability.
- **Appointment Booking:** Handle service bookings, scheduling, rescheduling, and cancellations.
- **Beautician Management:** Manage beautician profiles, availability, and assigned appointments.
- **Vendor Management:** Support vendor-related operations.
- **Admin Management:** Centralized platform and user management.
- **Payment Management:** Support payment-related operations and transaction tracking.
- **RESTful APIs:** Structured and scalable API architecture.

### Tech Stack

- Node.js (ES Modules)
- Express.js
- MySQL (`mysql2/promise`)
- JavaScript
- JWT Authentication
- REST API
